The session header, the Claude Code way

Liner Code's bar and Claude Code's carry nearly the same things: a title, a menu, what changed, and the panels. Claude Code's reads calmer because it says less in the bar and draws every button the same. Below are two ways to take that over, and five icon families to draw them with.

A brings back a row of surface buttons, which 0.2.2 took out of the bar this morning. This one is icon-only and fixed at four surfaces and ⋯, the way Claude Code does it. Apps you pin would join the row as icons after Files.

Icon families

The header's twelve glyphs in each family, at the size the bar uses. Click a family to put it in the window above. Lucide, Phosphor and Tabler are open source with permissive licences, so any of them could ship.

Recommendation

Build A with Liner, redrawn. A is the closest to Claude Code: one flat band, a grey title with a chevron, and icon buttons of one size. The redrawn set keeps Liner's own grid and stroke, so the header still matches the other 95 icons in icons.tsx. Only these twelve change.

If you'd rather use Lucide, which comes closest to Claude Code's own glyphs, switch the whole app in one go. Putting it in the header alone would leave two drawing styles side by side. Redrawing all 107 is a separate, bigger job.

B is the smaller step: the same structure as today, with the colour and the mixed glyphs taken out.

  • ui/src/app/TopBar.tsx the row of icon buttons, the Changes count dot, ⋯ for the rest
  • ui/src/app/Session.tsx the title as a menu button, the verdict as text, the branch into the menu
  • ui/src/app/icons.tsx the twelve glyphs
  • ui/src/app/app.css and dock.css the flat band, its hairline, the panel without its strip
